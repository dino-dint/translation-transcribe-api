## API Endpoints

### 1. Transcribe Audio
**POST** `/transcribe/`

Transcribe an audio file and detect language.

**Request:**
```bash
curl -X POST "http://localhost:8000/transcribe/" \
  -F "file=@audio.mp3" \
  -F "model=base"  # optional: tiny, base, small, medium, large
```

**Response:**
```json
{
  "detected_language": "en",
  "transcript": "Hello, this is a test transcription."
}
```

### 2. Manual Translation
**POST** `/translate`

Translate text between English and Khmer.

**Request:**
```bash
curl -X POST "http://localhost:8000/translate" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello world",
    "direction": "en_to_km"
  }'
```

**Response:**
```json
{
  "original": "Hello world",
  "translated": "សួស្តី​ពិភពលោក",
  "direction": "en_to_km"
}
```

**Direction options:**
- `en_to_km` - English → Khmer
- `km_to_en` - Khmer → English

### 3. Transcribe & Auto-Translate (Combined)
**POST** `/transcribe-and-translate`

Transcribe audio and automatically translate to opposite language.

**Request:**
```bash
curl -X POST "http://localhost:8000/transcribe-and-translate" \
  -H "Content-Type: application/json" \
  -d '{
    "transcript": "Hello world",
    "detected_language": "en"
  }'
```

**Response:**
```json
{
  "transcript": "Hello world",
  "detected_language": "en",
  "translation": "សួស្តី​ពិភពលោក",
  "translation_direction": "en_to_km"
}
```

### 4. Get Current Models
**GET** `/models`

Get currently loaded Whisper model.

**Response:**
```json
{
  "whisper_model": "base"
}
```

### 5. Update Models
**PATCH** `/models`

Change Whisper model at runtime (no restart needed).

**Request:**
```bash
curl -X PATCH "http://localhost:8000/models" \
  -H "Content-Type: application/json" \
  -d '{"whisper_model": "small"}'
```

**Response:**
```json
{
  "whisper_model": "small"
}
```

## Configuration

### Whisper Models

Available models (faster-whisper):
- `tiny` - Fastest, ~1GB VRAM, good for quick transcription
- `base` - Default, ~1.5GB VRAM, balanced performance
- `small` - Better accuracy, ~2GB VRAM
- `medium` - High accuracy, ~5GB VRAM
- `large` - Best accuracy, ~10GB VRAM (GPU recommended)

**Default:** `base`

Change in `app/config.py`:
```python
WHISPER_MODEL = "base"  # Change to your preferred model
```

### Environment Variables

Create a `.env` file (if needed):
```bash
WHISPER_MODEL=base
HOST=0.0.0.0
PORT=8000
```

Load in `app/config.py`:
```python
from dotenv import load_dotenv
load_dotenv()
```

## Performance Tips

- **First run**: Whisper will download model (~1-5GB depending on size)
- **Audio processing**: CPU is fine, but GPU (CUDA) is much faster
- **Model caching**: Models are cached in memory after first load
- **Translations**: Google Translate is fast (~1-2 seconds per request)

## Troubleshooting

### Issue: "Module not found" error
**Solution:**
```bash
pip install -r requirements.txt
```

### Issue: CORS errors from external network
**Status:** ✅ Already enabled in `main.py`

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Accepts from any origin
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Issue: Audio file not supported
**Solution:** Whisper supports: MP3, WAV, M4A, FLAC, OGG
- Convert your file to one of these formats
- Use FFmpeg: `ffmpeg -i input.mp4 -q:a 0 -map a output.mp3`

### Issue: Slow transcription
**Solution:**
- Use smaller model: `tiny` or `base`
- Use GPU (if available): Modify `app/services/transcription_service.py`
  ```python
  WhisperModel(name, device="cuda", compute_type="float16")
  ```

### Issue: Memory issues with large models
**Solution:**
- Use smaller models (`tiny`, `base`)
- Increase Docker memory: `docker run -m 4g ...`

## Deployment

### Public Access (Non-Network)

#### Option 1: Cloud Deployment (Recommended)

```bash

```

- Use Tailscale for secure remote access
- No port forwarding needed
